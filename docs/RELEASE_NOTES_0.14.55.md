### 1-2. 게이트 — 내용주소 비교 · 감시 6종 · fail-closed (`3873cb0f` → `8016cd30`)

- 새 파일 `scripts/copy-drift-check.py` 가 `main`(기준)과 발행 가능한 ref 의 **같은 파일이 같은지**를 봅니다. 비교는 **내용주소(git blob sha)** 입니다 — `GET /repos/<repo>/contents/<path>?ref=main` 의 `.sha` 가 git blob sha 와 **같은 값**이라는 실측(3/3 일치)에 기대므로 다운로드·재해시·개행 정규화가 전부 불필요하고 **1바이트 차이도 잡습니다.**
- **감시 6종**: `.github/workflows/release-publish.yml` · `scripts/release-verify.py` · `scripts/tests/test_release_verify.py` · `.github/workflows/release.yml` · `.github/workflows/release-postprocess.yml` · `scripts/copy-drift-check.py`(**자기 자신** — `main` 사본이 낡으면 일일 감시가 엉뚱한 목록으로 초록을 내므로).
- **fail-closed**: 부재(404) · API 오류 · 네트워크 실패는 전부 **실패**입니다. 「재지 않았다」를 통과로 접지 않습니다.
- **길이가 아니라 경로 문자열을 전수 단언합니다**: 자기시험이 `len == 6` 만 보면 6개가 **다른** 6개로 바뀌어도 통과하므로, 기대 경로 6개를 자기시험 안에 리터럴로 두고 **순서까지 원소별로** 단언합니다(그 리터럴은 감시 목록을 참조하지 않습니다 — 참조하면 계기가 자기를 재는 항진명제가 됩니다).
- **게이트가 어디에 걸리는가**: `release.yml`(태그 레인 **하드게이트** — 빨강이면 자산 생산이 멈춥니다)과 새 `copy-drift-watch.yml`(**일일 조기경보** · 매일 21:17 UTC = 06:17 KST). 같은 비교를 두 워크플로에 **복사해 넣으면 고치려는 병을 고치는 중에 다시 만들기** 때문에 단일 출처는 그 스크립트 하나입니다.
- **조기경보가 빨강을 내보내는 방법**: PR 체크가 아니라 `gh issue create` 입니다. 같은 이슈가 **열려 있으면 새로 만들지 않습니다**(검색으로 먼저 확인). ⚠**이 멱등성은 실측되지 않았습니다** — §3-2.

### 1-3. 허용 ref 단언 — 경고로 시작했고 같은 날 치명으로 올렸다 (`8016cd30` → `3f1de377`)

- **왜 경고로 시작했나**: 드리프트 비교 축은 측정됐지만, `GITHUB_TOKEN`(잡 권한 `contents: read`)이 `GET /environments/release-production/deployment-branch-policies` 에 **도달하는지**가 미측정이었습니다. 403 이면 fail-closed 가 **모든 릴리스를 막고**, 그러면 위험이 제거되지 않고 **「사람이 게이트를 끄는 것」으로 이동합니다** — 가장 나쁜 착지입니다. 「측정 불능은 통과도 실패도 아니다」 ⇒ 판정은 그대로 계산·출력되고 경고로 밖에 나가지만 종료코드에는 반영되지 않게 두었습니다.
- **무엇이 그 사유를 소멸시켰나**: `copy-drift-watch.yml` 을 `workflow_dispatch` 로 **1회** 돌린 런 `40285752606`(2026-10-26T07:25:58Z · head_sha `f27879cb` · actor idoforgod)의 로그가 **허용 ref 단언이 기대 2건과 실측 2건으로 일치하며 통과했다**고 적습니다. ⇒ 토큰이 그 환경정책 API 에 **도달했습니다** ⇒ UNMEASURED 가 아닙니다.
- **그래서 같은 날 올렸습니다**: `release.yml` 게이트 step 과 스크립트 **기본값**을 모두 치명(fatal)으로 올렸습니다. 기본값이 경고로 남으면 손으로 돌린 실행만 조용히 옛 상태를 쓰게 되고 — 그것이 이 티켓이 고치는 바로 그 병(사본·기본값 드리프트)입니다.
- **되돌리는 조건을 코드 옆에 한 줄로 박았습니다**: 이 단언이 조회 실패로 릴리스를 막기 시작하면 **게이트를 끄지 말고 그 조회 실패를 먼저 측정하라**(「조회 실패」와 「정책 변경」은 서로 다른 문장으로 나옵니다). 권한 회수가 확인되면 그때 경고로 내리고 날짜와 근거를 그 자리에 적습니다.
- **치명화가 장식이 아님을 주입으로 보였습니다**(전부 GET 주입 · 워크플로 실행 0): 조회 실패 주입(없는 환경 ⇒ 404) ⇒ 치명·rc=1 · 정책 변경 주입(실재 `github-pages` — 그 정책은 `main` 을 포함합니다) ⇒ 치명·rc=1 · 같은 둘을 경고로 내리면 rc=0 ⇒ **모드가 원인임이 고정됩니다.**
