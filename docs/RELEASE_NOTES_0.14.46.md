# v0.14.46 — 사용량 칸의 "사용처:" 줄을 뺐습니다(부서 카드의 계정 줄과 겹치던 것)

> 2026-10-08 · v0.14.46 — 수치는 실제로 잰 것만 적었고, 재지 못한 것(윈도우 실기 · 로그인 계정이 있는 화면에서의 눈 확인)은 §3 · §4 에 숨기지 않고 적었습니다.

바뀐 것은 한 가지입니다. **v0.14.45 는 "어느 부서의 어느 노드가 어느 계정을 쓰는가"를 사이드바의 두 곳 — 위쪽 부서 카드의 계정 줄과
아래쪽 사용량 칸의 `사용처:` 줄 — 에 함께 보여 줬습니다. 같은 사실을 뒤집어 적은 중복이라, 사용량 칸의 `사용처:` 줄을 뺐습니다.**
이제 그 정보는 부서 카드의 계정 줄 한 곳에서만 보입니다.

## 1. 바뀐 것

- 사이드바 사용량 칸의 계정마다 붙던 회색 `사용처: …` 줄이 없어졌습니다(큰 상자 · 한 줄형 · "나머지 N개"를 펼친 줄 모두).
- 그 줄만을 위해 있던 화면 코드를 함께 뺐습니다 — `ui/src/main.ts` 의 표시와 인자, `ui/src/usagebar.ts` 의 모델 칸(`users`),
  `ui/src/seatacct.ts` 의 역매핑 함수(`accountUsers`), `ui/src/style.css` 의 `.usage-users` 규칙, 그것만을 재던 시험 3건.
  한 줄형과 계정 줄의 화면 코드는 v0.14.44 의 모양과 같습니다.
- 사용 설명서의 「부서별 노드 계정」 절을 이 사실에 맞게 고쳤습니다.

## 2. 그대로인 것

- **부서 카드의 계정 줄**(`claude-4 master·worker · claude cso · Codex rv-codex` 꼴 · `계정 미확인` · `계정 확인 중` · `계정 불일치·확인 필요` 묶음과 툴팁) — 손대지 않았습니다.
- **사용량 칸의 나머지 전부** — 5시간·7일 수치와 막대 · 리셋 시각 · 소진 예상 · `● 사용 중` 표지 · 관측 시각 · 머리줄 요약 · 보기 방식 · 접기 · 숨기기.
- 데몬 · CLI · 팩 · 역할 지침 — **변경 없음**. 데몬이 좌석마다 싣는 `account` 키도 그대로입니다(부서 카드가 씁니다).
  데몬 소스의 주석 두 곳(`src/bin/cysd/accounts.rs` · `handlers.rs`)은 아직 그 키의 쓰임을 "부서 카드 · 사용량 패널 역매핑"이라고 적고 있습니다 — 이번 판에서 고치지 않았습니다.
- 맥과 윈도우 공통입니다 — 바뀐 줄에 플랫폼을 가르는 코드가 없습니다(0행).

## 3. 알려진 한계 — 정직하게

- **눈으로 본 화면 확인이 없습니다.** 로그인 계정이 있는 화면에서 사용량 칸을 직접 보고 확인한 것이 아니라, 화면 시험과 묶은 화면 파일의 문자열 수로 확인했습니다.
  사용량 칸의 줄 수가 줄면서 그 아래 칸의 놓임이 어떻게 달라지는지도 화면으로 보지 않았습니다.
- **윈도우 실기: 미측정.** 같은 화면 코드가 윈도우 앱에도 묶이지만 윈도우에서 띄워 본 것은 아닙니다.
- 화면 관문 스크립트(`ui/e2e/`)는 돌리지 않았습니다(그 스크립트들에 이 줄을 보는 검사는 없습니다 — 0건).
