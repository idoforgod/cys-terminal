# cys 터미널 v0.14.17

## 완전 초기화(팩토리 리셋) — 연습 흔적을 한 번에 지우고 "처음 설치" 상태로

자비스를 연습해 보는 동안 만든 부서·워커·세션·대화기억이 정식 사용으로 넘어갈 때 계속 살아나
충돌한다는 보고를 받았습니다. 앱 안에서 "초기화해줘"라고 시켜도 부서와 상태는 남고, 손으로
지우자니 절차가 길며, 잘못 지우면 인증서·라이선스처럼 지우면 안 되는 파일까지 날아갑니다.

이번 릴리스는 그 일을 **버튼 하나**로 만듭니다.

> ### 먼저 읽을 것 — 삭제가 아니라 **격리**입니다
>
> 완전 초기화는 파일을 지우지 않습니다. 전부
> `~/.local/state/cys-trash/factory-reset-<시각>/` 로 **옮겨 보관**하고, 그 폴더 안에
> 복구 지도(`manifest.json`)와 사람이 읽는 결과 요약(`REPORT.txt`)을 함께 남깁니다.
> 되돌리려면 한 줄이면 됩니다:
>
> ```bash
> cys factory-reset --undo ~/.local/state/cys-trash/factory-reset-<시각>
> ```
>
> **지우지 않는 것**: 라이선스 · 직접 만든 설정(`~/.cys/local` — 지침·스킬·훅) ·
> `~/.cys`에 직접 넣은 파일(인증서 `.env` 등) · **작업 프로젝트 폴더 안의 작업기억**.
> 마지막 항목은 "여기는 남습니다"라고 화면에 경로까지 적어 알려 주고, 그것까지 지우려면
> `--purge-round` 를 따로 붙여야 합니다.

### 쓰는 법

- **앱**: 상단바 **완전 초기화** → 무엇이 사라지는지 확인 → `완전 초기화` 타이핑 → 실행 → 앱 종료
- **터미널**: `cys factory-reset` (미리보기는 `cys factory-reset --plan` — 아무것도 바꾸지 않습니다)

앱을 다시 실행하면 설치 온보딩이 처음부터 시작됩니다.

### 승인 전에 무엇이 사라지는지 다 보여줍니다

확인 창이 숫자만 보여주고 승인받는 일이 없도록 했습니다. 실행 중인 세션·부서 수와 "저장 신호
없이 즉시 종료된다"는 사실을 맨 위에 두고, **내 폴더 안에서 사라지는 항목은 경로와 용량을 따로
강조**합니다. 자동으로 정리하지 않는 잔재(`.zshrc` 별칭, 다른 도구의 설정)도 함께 알려 줍니다.
터미널 `--plan` 은 분류별 소계와 큰 항목부터 보여주고, 전량은 `--verbose` 로 봅니다.

### 안전장치

- **에이전트는 실행할 수 없습니다.** 마스터·워커·리뷰어가 이 명령을 쓰면 팩 가드가 평시·자율주행
  구분 없이 차단합니다. 환경변수를 지워 우회하는 시도도 함께 막힙니다. 오너의 경로는 앱 버튼과
  에이전트 창 밖 터미널입니다.
- **데몬이 살아 있으면 옮기지 않습니다.** 자동 재시작 등록을 먼저 끊고, 전부 종료된 것을 실제로
  확인한 뒤에만 격리를 시작합니다. 앱이 켜져 있으면 터미널 실행을 거부합니다(앱이 데몬을
  되살리기 때문입니다).
- **중간에 멈춰도 복구할 수 있습니다.** 각 항목은 옮기기 **직전**에 복구 지도를 디스크에 적고
  나서 움직입니다. 지도를 못 적으면 그 항목은 옮기지 않습니다.
- **실패를 성공처럼 보고하지 않습니다.** 일부만 정리됐으면 제목부터 "부분 완료"이고, 무엇이 왜
  남았는지 창과 `REPORT.txt` 양쪽에 적습니다.

### 함께 고친 것

- **첫 부팅에 정기 작업이 한꺼번에 몰리던 문제**: 상태 파일이 없는 첫 가동에서 6시간·하루·주간
  작업의 만기가 동시에 성립해, 갓 깨어난 마스터에게 한꺼번에 주입되거나(작업 폭주) 마스터가
  없으면 전부 소인돼 침묵했습니다. 첫 가동에는 기준 시각을 현재로 맞춰 다음 주기부터 정상
  리듬을 타게 했습니다. **이 수정은 완전 초기화와 무관하게 모든 신규 설치의 첫 부팅에
  적용됩니다**(첫 주기가 한 번 늦어지는 것이 유일한 변화입니다).
- 도트파일 저장소처럼 `settings.json` 을 심볼릭 링크로 쓰는 구성에서 훅 정리가 되지 않던 문제
- Windows에서 이전 상태표시줄 설정이 복원되지 않고 사라지던 문제
