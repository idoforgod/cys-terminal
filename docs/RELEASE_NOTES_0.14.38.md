## 1. 상단바 — 글자 버튼 다섯 개가 아이콘이 됐습니다

왼쪽 그룹의 `+ New` · `Split →` · `Split ↓` · `Close` · `Files` 가 ＋ · 사각형+세로 분할선 · 사각형+가로
분할선 · × · 폴더 아이콘이 됐습니다. **동작·단축키·바인딩은 그대로**이고(버튼 `id` 와 툴팁 `title` 이
`main.ts` 바인딩 계약이라 바꾸지 않았습니다), 마우스를 올리면 툴팁에 이름과 단축키가 뜹니다.
`정렬` · `Control Center` · `Update` · `테마` 는 글자 그대로입니다.

- 이모지·아이콘 폰트 대신 **인라인 SVG** 로 그립니다 — Windows 의 폰트 사정에 좌우되지 않기 위해서입니다.
  선 색은 `currentColor` 라 상단바 글자색을 따르고, 배경색을 사용자가 바꿔도 상단바는 건드리지 않는 기존
  규칙(`applyBgColor` 는 `--bg`·`--canvas-text` 만) 덕에 밝은 배경에서도 대비가 같습니다(정적 시뮬 스크린샷).
- 접근성 이름은 `aria-label`, SVG 는 `aria-hidden` 이라 화면낭독기에 두 번 읽히지 않습니다. 클릭 영역은
  16px 그림이 아니라 **28×26px 버튼 전체**입니다.
- ＋ 버튼의 이름은 **`새 창`** 입니다(`title`·`aria-label` 둘 다 `새 창 (⌘T)`). 매뉴얼 §4.1 과 빈 창 안내
  문서의 옛 글자 라벨(`+ New`·`Files`)을 아이콘 표기로 맞췄습니다 — **이름 자체를 바꾸지는 않았습니다.**

#### E. 묘비를 못 읽은 기동 — 탭과 창 배치는 그대로, 자동 기동만 보류합니다

## 3. 하드웨어 조사 결과 · 후속 티켓 (코드 변경 없음)

오너 질문 셋에 대한 결론입니다(`01-hardware/REPORT.md` §1). ① **맥 NPU 는 "못 쓰는" 게 아니라 쓸 일이
없습니다** — NPU(ANE)는 Core ML 추론 전용이고 자비스 워크로드(PTY·JSON IPC·터미널 텍스트 렌더링·규칙 기반
파이썬 도구)에 ML 추론이 없으며 바이너리 셋 어느 것도 CoreML/Metal 을 링크하지 않습니다. 컨트롤센터의 NPU
0 W 표시는 정상 값이 아니라 macOS 27 에서 정지된 IOReport 채널을 읽는 **관측 결함**입니다. ② **Windows GPU
는 코드가 끈 것이 아닙니다** — GPU 를 끄는 플래그·환경변수가 0건이고 WebView2 기본값은 GPU 켜짐입니다.
유력 원인은 터미널이 xterm.js DOM 렌더러라 GPU 가 할 일이 창 합성뿐인 구조(맥과 같음)이며, 확정은 Windows
실기가 필요합니다. ③ **현재 구성에서 NPU 는 의미 없는 자원이 맞습니다** — 온디바이스 ML 기능(음성 전사·임베딩
회상·OCR·소형 라우터)을 넣기로 결정할 때만 의미가 생기고, 그때도 Apple 프레임워크를 쓰면 자동으로 쓰입니다.

## 5. 알려진 한계 · Windows 실기 체크리스트

**맥 한글 홈 폴더는 결함이 아닙니다(20/20).** 다만 이 맥에는 sudo 가 없어 실제 한글 계정을 만들지 못했고,
`$HOME` 문자열이 NFC 인지 NFD 인지는 미확정입니다(근사: 격리 HOME `홍길동`(NFC) · `박`(NFD 디스크·NFC env)).
제품 문서는 ASCII 계정 이름을 권고합니다.

**Windows 는 전부 "코드 수정(실기 미검증)" 입니다.** 이 판을 한글 계정(`C:\Users\홍길동` · 한국어 로캘 · cp949
콘솔)에서 쓰신다면 아래를 확인해 주세요 — 어긋나면 `cys-dept` 종료코드·stderr·부서 `cysd.log`·파일 인코딩을
함께 보내 주시면 됩니다.

- [ ] **자동기동 등록** — 설치 후 첫 부팅 뒤 `schtasks /Query /TN cysd /XML` 에 `<UserId>…\홍길동</UserId>` 가 한글
      그대로 있고, `.gui-onboarded` 마커가 생기며, **재부팅 후 데몬이 자동으로 뜨는지**. Git Bash 에서 `whoami | od -c`
      로 cp949 바이트 여부를 함께 기록해 주세요.
- [ ] **AzureAD/도메인 계정** — `%USERDOMAIN%\%USERNAME%` 과 `whoami` 표기가 다를 때 등록이 성공하는지(`AzureAD\…`
      문자열의 SID 해석은 근거를 찾지 못했습니다).
- [ ] **MSYS bash 의 `$(...)` 줄끝 `\r`** — `cys-dept allocate` 가 돌려준 이름을 `printf %s "$name" | od -c` 로 확인.
      부서명 캡처 전부가 "`$(...)` 는 `\r` 을 벗긴다"는 관측 2건에 기대고 있습니다(bash 소스 근거 없음).
- [ ] **GUI 가 넘기는 `HOME=C:\Users\홍길동`(백슬래시)** — `C:\Users\홍길동/.cys/depts.json` 같은 혼합 구분자 경로로
      `create`·`launch` 가 완주하는지. CI 는 POSIX 형 HOME 만 돌려 이 형상은 ASCII 로도 미실행입니다.
- [ ] **편집기 저장 형식** — 메모장 "UTF-8(BOM)" 으로 저장한 `depts.json`·`dept-catalog.json` 이 GUI 팝업 · `cys-dept
      list` · ＋부서 `create` 에서 같게 보이고 첫 쓰기 뒤 BOM 이 사라지는지. **"유니코드(UTF-16)" 저장은 여전히 판독
      실패**이며, 이 판은 그때 덮어쓰지 않고 exit 10 으로 멈춥니다(§2 C).
- [ ] **`create` 뒤 등재 `cwd`** — `depts.json` 의 `cwd` 끝에 `\r` 이 없고 `resolve_dept_cwd` WARN 이 없는지. Windows
      CI 는 `create` 성공 경로를 0회 돌립니다.
- [ ] **백신 활성 기계에서 `launch`/`down` 반복** — 다른 등재 2건이 유지되는지(공유 위반 → 등재 소실 경로 프로브).
- [ ] **한글 표시명으로 개명한 탭** — 앱 재기동 뒤 등재된 부서명으로 켜지고 "이름을 확인하지 못했습니다" 토스트가 없는지.
- [ ] **대소문자만 다른 부서명 재생성** — `Sales` 를 지우고 `sales` 를 새로 만든 뒤 앱을 다시 켰을 때 `sales` 가
      그대로 살아 있는지(fold 폐기가 실제로 반영됐는지 · 그 탭에 옛 표기 소켓이 저장돼 있으면 §6 티켓 1 에 걸릴 수 있습니다).

- GUI 의 판독 실패 경고(`warn_json_read_err`)는 stderr 라 Windows GUI(no_console)에서는 보이지 않습니다 — 기능
