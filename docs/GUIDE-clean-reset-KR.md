# CYSJavis(cys 터미널) 완전 초기화 가이드 — 생초보용

> **이런 분을 위한 문서입니다**
> "작업이 이상하게 쌓였어요", "부서를 지웠는데 자꾸 남아 있어요",
> "세팅 다 없어져도 좋으니 **포맷하듯 싹 지우고 처음부터** 시작하고 싶어요."
>
> PC 전체를 포맷할 필요는 전혀 없습니다. 아래 순서대로 하면
> cys 터미널과 관련된 것만 깨끗하게 지워지고, 새로 설치하면 완전히 처음 상태로 시작합니다.

> 💡 **먼저 이걸 시도하세요 — 앱을 지우지 않는 원버튼 초기화.**
> 앱은 그대로 두고 데이터만 처음 상태로 되돌리면 충분한 경우(대부분이 이 경우입니다),
> 이 문서 대신 앱 상단의 **완전 초기화** 버튼(또는 터미널에서 `cys factory-reset`)을
> 쓰세요. 자동으로 안전하게 정리하고, 지운 것은 격리 보관되어 되돌릴 수도 있으며
> (격리 폴더의 `manifest.json` 참조), 라이선스·직접 만든 설정·직접 넣은 파일은 보존됩니다.
> 터미널로 실행할 때는 **앱을 먼저 종료**하세요.
>
> **되돌리고 싶다면**: 초기화가 끝나면 화면이 격리 폴더 위치를 알려줍니다. 그 폴더를 그대로
> 넣어 아래 한 줄을 실행하면 원래대로 돌아옵니다(이미 새로 만들어진 것은 덮어쓰지 않습니다).
> ```bash
> cys factory-reset --undo ~/.local/state/cys-trash/factory-reset-<시각>
> ```
> 아래 절차는 **앱까지 완전히 제거**할 때만 필요합니다(이 절차는 되돌릴 수 없습니다).

---

## 시작하기 전에 — 딱 2가지만 알아두세요

**1. 이 작업을 하면 아래가 전부 사라집니다. (되돌릴 수 없습니다)**

- 열려 있던 모든 세션(마스터·워커·부서 포함)과 대화 기록
- 만들었던 부서 전부
- cys 관련 설정·상태 파일 전부
- ★**앱 안의 "완전 초기화" 버튼이라면 남겨 두었을 것들까지** — 라이선스 파일,
  직접 만든 지침·스킬·훅(`local` 폴더), 직접 넣어 둔 열쇠 파일(`*.env`)·인증서,
  그리고 지금까지의 격리 보관본(`cys-trash` — 초기화를 되돌리는 창구)
  → 그래서 맥은 2단계 **⑤-A 에서 먼저 복사**하고(홈 폴더에 `cys-keep-<날짜-시각>` 이 생깁니다),
  윈도우는 2단계 **4번에서 `.cys` 폴더를 복사한 뒤** 지웁니다.

"다 없어져도 된다"는 분만 진행하세요. 남기고 싶은 결과물 파일(문서·코드 등)이
바탕화면이나 내 문서 같은 **일반 폴더**에 있다면 그건 지워지지 않으니 안심하세요.
지워지는 것은 **cys 앱과 cys 전용 데이터 폴더들**(숨김 폴더 `.cys`·상태 폴더·화면 저장값)뿐입니다.

**2. 왜 앱 안에서 CEO에게 "초기화해줘"라고 해도 부서가 남을까요?**

부서 목록과 상태는 앱이 아니라 사용자 폴더 안의 숨김 폴더(`.cys`)에 저장되고,
부서마다 배경 프로그램(데몬)이 따로 떠 있습니다. 앱 안에서 내리는 명령은 이걸
전부 지우지 못합니다. 그래서 **밖에서(운영체제에서) 지우는 것**이 확실한 방법입니다.
이 문서가 그 방법입니다.

# 윈도우(Windows) 사용자

## 1단계 — 앱을 제거합니다

1. 키보드에서 **윈도우 키**를 누르고 **"앱 추가/제거"** 라고 입력한 뒤 Enter.
2. 목록 검색창에 **cys** 라고 입력합니다.
3. **cys** 항목 오른쪽의 **⋯ → 제거**를 누르고, 다시 **제거**를 누릅니다.

> 제거 프로그램이 실행 중인 cys 관련 프로그램(데몬·부서 데몬 포함)을 **전부 강제
> 종료**하고 앱을 지웁니다. "실행 중이라 지울 수 없다"는 걱정은 하지 않아도 됩니다.

## 2단계 — 남은 데이터 폴더를 지웁니다 (부서가 여기 들어 있습니다)

1. **파일 탐색기**를 엽니다 (윈도우 키 + E).
2. 위쪽 **주소창**을 클릭하고 아래를 그대로 입력한 뒤 Enter:
   ```
   %USERPROFILE%
   ```
3. 목록에서 **`.cys`** 폴더를 찾습니다.
   - 안 보이면: 탐색기 위 메뉴 **보기 → 표시 → 숨긴 항목**에 체크하세요.
4. 🚧 **지우기 전에 통째로 복사해 두세요.** `.cys` 폴더를 **Ctrl+C → 바탕화면에 Ctrl+V** 로
   한 벌 복사한 뒤, 원본 `.cys` 폴더를 **마우스 오른쪽 클릭 → 삭제**.
   - 왜: 이 폴더 안에는 앱의 "완전 초기화" 버튼이라면 **남겨 두었을 것들**이 함께 들어 있습니다 —
     라이선스 파일(`license.json`·`license.json.minisig`), 직접 만든 지침·스킬·훅(`local` 폴더),
     직접 넣어 둔 열쇠 파일(`*.env`)·인증서. 폴더째 지우면 그것들도 함께 사라집니다.
   - 복사본은 나중에 정말 필요 없다고 확인한 뒤에 지우세요.
5. 같은 방법으로 주소창에 아래를 입력해 이동한 뒤, **`cys`** 폴더와
   **`com.cysjavis.terminal`** 폴더(앱 화면 저장값 — 테마·화면 배치)가 남아 있으면 둘 다 삭제:
   ```
   %LOCALAPPDATA%
   ```
6. 마지막으로 주소창에 아래를 입력해 이동한 뒤, **`state`** 폴더 안에 **`cys-trash`**
   폴더(앱에서 "부서 완전삭제"를 쓴 적이 있으면 그 격리 보관본)가 있으면 삭제:
   ```
   %USERPROFILE%\.local
   ```
   (`.local` 폴더 자체가 없으면 이 단계는 건너뛰세요.)

> `.cys` 폴더가 바로 "부서가 계속 남아 있던" 이유입니다. 부서 목록·세션 상태·팩이
> 전부 이 안에 있어서, 앱만 지우고 이 폴더를 안 지우면 재설치 후에도 그대로 돌아옵니다.
> 부서별 대화 기록은 `%LOCALAPPDATA%\cys` 안에 있어 **이 2단계의 5번**에서 함께 지워집니다.

## 3단계 — (제거가 안 될 때만) 강제 종료 후 다시 시도

1단계에서 "지울 수 없다"는 오류가 나오는 드문 경우에만 하세요.

1. 윈도우 키를 누르고 **cmd** 입력 → **명령 프롬프트**를 **관리자 권한으로 실행**.
2. 아래 줄들을 한 줄씩 붙여넣고 Enter (오류가 나는 줄은 무시하고 다음 줄 진행):
   ```
   taskkill /F /T /IM cys-app.exe
   taskkill /F /T /IM cysd.exe
   taskkill /F /T /IM cys.exe
   taskkill /F /T /IM cysd.prev.exe
   taskkill /F /T /IM cysd.prev2.exe
   taskkill /F /T /IM cysd.prev3.exe
   taskkill /F /T /IM cys.prev.exe
   taskkill /F /T /IM cys.prev2.exe
   taskkill /F /T /IM cys.prev3.exe
   ```
3. 다시 1단계(앱 제거) → 2단계(폴더 삭제)를 진행합니다.

## 4단계 — 다 지워졌는지 확인

1. **Ctrl + Shift + Esc**로 작업 관리자를 엽니다.
2. 검색창에 **cys**를 입력합니다. → **아무것도 안 나오면 성공**입니다.

## 5단계 — 새로 설치해서 처음부터

홈페이지(www.cysinsight.com)에서 최신 설치 파일을 받아 설치하면
계정·부서·세션이 하나도 없는 **완전한 처음 상태**로 시작합니다.

# 맥(macOS) 사용자

맥은 데몬이 "죽어도 자동으로 되살아나게" 등록되어 있어서 **순서가 중요합니다.**
그냥 프로그램을 종료하면 몇 초 뒤 되살아납니다. 아래 순서 그대로 하세요.

## 0단계 — 앱이 아직 열린다면 **"셸 cys 해제"를 먼저** 누르세요

터미널에서 `cys` 명령을 쓰려고 Control Center 헤더의 **"셸에 cys 설치"** 를 누른 적이 있다면,
앱을 지우기 **전에** 같은 자리의 **"셸 cys 해제"** 를 먼저 누르세요(관리자 승인 1회).

- 이 버튼은 `/usr/local/bin/cys`·`/usr/local/bin/cysd` 중 **이 앱이 만든 바로가기(심볼릭 링크)만**
  지웁니다. 같은 이름의 **남의 진짜 파일**은 사유를 적고 건드리지 않습니다.
- 설치할 때 그 자리에 있던 남의 파일을 밀어내 **백업해 둔 것**(`cys.cys-backup-<숫자>`)이 있으면,
  해제가 그것을 **제자리에 되돌려 놓습니다.**
- 앱을 먼저 지워 버리면 그 되돌리기를 해 줄 주체가 사라져서, 백업본이 `/usr/local/bin` 에
  주인 없이 남습니다. 그래서 이 단계가 **맨 앞**입니다.

### 0단계를 건너뛰어도 되는 경우 — **어느 경우든 다음은 1단계입니다**

| 지금 상황 | 어떻게 하나 |
|---|---|
| **"셸에 cys 설치"를 누른 적이 없다** | 0단계 생략 → **1단계**로. `/usr/local/bin` 에 우리가 만든 것이 없으니, 나중에 3단계는 목록만 보고 지나가게 됩니다. |
| **눌렀지만 앱이 이미 열리지 않는다**(또는 앱을 이미 지웠다) | 0단계는 이제 할 수 없습니다 → **1단계**로 가되, 2단계를 마친 뒤 **3단계를 반드시** 하세요. `/usr/local/bin` 에 우리 바로가기나 남의 원본 백업본이 주인 없이 남아 있습니다. |

> ⚠ **0단계를 건너뛴다는 말은 1·2단계를 건너뛴다는 뜻이 아닙니다.**
> 1단계(터미널 열기)와 2단계(자동 부활 해제 → 프로그램 종료 → 앱 삭제 → 데이터 삭제 → 화면
> 저장값 삭제)를 하지 않으면 **초기화가 되지 않습니다.** 이 문서의 초기화는 2단계가 전부입니다.
> (2026-08-25 이전 이 자리에는 "0단계는 건너뛰고 3단계를 보세요"라고 적혀 있었습니다. 그대로
> 따르면 1·2단계를 통째로 건너뛰어, **완전 초기화 가이드인데 아무것도 초기화되지 않았습니다.**)

## 1단계 — 터미널을 엽니다

**Spotlight(돋보기, Cmd + Space)** → **터미널** 입력 → Enter.

## 2단계 — 아래 명령을 위에서부터 한 줄씩 붙여넣고 Enter

```bash
# ① 자동 부활 장치(launchd)부터 해제합니다 — 반드시 첫 번째로!
launchctl bootout gui/$(id -u)/com.cysjavis.cysd

# ② 자동 부활 등록 파일 삭제
rm -f ~/Library/LaunchAgents/com.cysjavis.cysd.plist

# ③ 아직 떠 있는 cys 프로그램 전부 종료 (부서 데몬 포함)
pkill -x cys-app; pkill -x cysd; pkill -x cys

# ④ 앱 삭제 (비밀번호를 물어보면 맥 로그인 비밀번호 입력)
#    🚧 되돌릴 수 없습니다. 다만 다시 쓰고 싶으면 홈페이지에서 새로 받아 설치하면 됩니다.
#    이름만 보고 지우지 않습니다 — 정말 이 앱의 번들일 때만 지웁니다(아래 두 검사).
sudo sh -c '
export PATH=/usr/bin:/bin:/usr/sbin:/sbin
A=/Applications/cys.app
if [ ! -e "$A" ] && [ ! -L "$A" ]; then echo "없습니다(이미 지웠습니다): $A"; exit 0; fi
if [ -L "$A" ]; then echo "중단: 그 자리는 바로가기입니다 — 직접 확인하세요: $A"; exit 1; fi
ID=$(defaults read "$A/Contents/Info" CFBundleIdentifier 2>/dev/null || echo "")
if [ "$ID" != "com.cysjavis.terminal" ]; then
  echo "중단: 이 앱의 번들이 아닙니다(읽은 식별자: ${ID:-읽지 못함}) — Finder 로 직접 확인하세요: $A"
  exit 1
fi
rm -rf "$A" && echo "지웠습니다: $A"
'

# ⑤-A 먼저 꺼내 둡니다 — 아래 ⑤-B 는 앱의 "완전 초기화"가 **남겨 두기로 한 것들**까지 지웁니다.
#     남겨 두기로 한 것: 라이선스 파일 · 직접 만든 지침·스킬·훅 폴더(local) ·
#     그리고 앱이 모르는 파일 전부(직접 넣어 둔 열쇠 파일 *.env·인증서 등).
#     ⑤-B 는 그것들을 되돌릴 수 없게 지우므로, 통째로 복사해 둡니다.
#     끝나면 홈 폴더에 cys-keep-<날짜-시각> 이라는 폴더가 생깁니다.
KEEP=~/cys-keep-$(date +%Y%m%d-%H%M%S)
mkdir -p "$KEEP" && cp -R ~/.cys "$KEEP"/ 2>/dev/null
ls -l "$KEEP"/.cys 2>/dev/null || echo "복사할 것이 없었습니다(.cys 폴더가 이미 없습니다)"
echo "보관 위치: $KEEP"

# ⑤-B 데이터·부서·세팅 전부 삭제 — 이 줄이 "포맷하듯 초기화"입니다
#     🚧 되돌릴 수 없습니다. **⑤-A 가 무엇을 보관했는지 눈으로 확인한 뒤에만** 실행하세요.
#     (부서마다 대화 기록이 cys-dept-부서명 폴더에 따로 있고, 앱에서 지운 부서의 격리 보관본과
#      예전에 "완전 초기화" 버튼으로 격리해 둔 보관본이 cys-trash 폴더에 남습니다
#      — 넷 다 지워야 진짜 전부입니다)
ls -d ~/.cys ~/.local/state/cys ~/.local/state/cys-dept-* ~/.local/state/cys-trash 2>/dev/null
# ↑ 방금 나온 목록이 지워집니다. 그대로 좋다면 아래 한 줄을 실행하세요.
rm -rf ~/.cys ~/.local/state/cys ~/.local/state/cys-dept-* ~/.local/state/cys-trash

# ⑥ 앱 화면 저장값(테마·화면 배치 등 앱이 브라우저 저장소에 남긴 설정) 삭제
rm -rf ~/Library/WebKit/com.cysjavis.terminal ~/Library/Caches/com.cysjavis.terminal
```

> - ①에서 "not found" 비슷한 말이 나와도 괜찮습니다(이미 꺼져 있다는 뜻).
> - ③에서 아무 반응이 없어도 괜찮습니다(이미 종료됐다는 뜻).
> - ④가 **"중단: 이 앱의 번들이 아닙니다"** 로 멈추면 억지로 지우지 마세요. 그 자리에 있는 것이
>   우리 앱이 아닐 수 있습니다. **Finder 로 응용 프로그램 폴더를 열어 `cys.app` 을 휴지통으로
>   옮기는 것**이 가장 안전합니다(휴지통은 되돌릴 수 있습니다).
> - ⚠ **`/usr/local/bin` 은 이 블록에 일부러 넣지 않았습니다.** 예전 판에는 여기에
>   `sudo rm -f /usr/local/bin/cys /usr/local/bin/cysd` 한 줄이 있었는데, 그 줄은 그 자리에 있는
>   것이 **우리 바로가기인지 남의 진짜 파일인지 보지 않고** 지웠습니다. Homebrew로 깔았거나 직접
>   빌드한 `cys` 를 쓰던 분은 그 파일이 **백업도 경고도 없이 사라졌습니다.** 그 정리는 3단계에서
>   확인 절차와 함께 합니다.

> 🚧 **⑤-B 는 앱의 "완전 초기화" 버튼보다 넓게 지웁니다 — 이것이 두 절차의 유일한 큰 차이입니다.**
> 앱 안의 **완전 초기화**(`cys factory-reset`)는 `.cys` 폴더를 통째로 옮기지 않고 **자기가 아는
> 항목만** 골라 격리하며, 다음 넷은 **일부러 제자리에 남깁니다**(근거: `src/factory_reset.rs` 의
> 보존 규칙):
> - **라이선스 파일** `license.json` · `license.json.minisig` (구매물 — `--purge-license` 를 줄 때만 격리)
> - **`local` 폴더** = 직접 만든 지침·스킬·훅·메모(업데이터가 손대지 않는 사용자 전용 영역 —
>   `--purge-local` 을 줄 때만 격리)
> - **앱이 모르는 파일 전부** — 직접 넣어 둔 열쇠 파일(`*.env`)·인증서 등은 "사용자가 둔 것"으로
>   보고 건드리지 않습니다
> - **`~/.local/state/cys-trash`** = 지금까지의 격리 보관본. 초기화의 **되돌리기 창구**라서 초기화가
>   절대 지우지 않습니다
>
> ⑤-B 의 `rm -rf` 는 이 넷을 **전부** 지웁니다. 앱까지 없애는 절차이므로 그것이 목적이긴 하지만,
> **모르고 지우면 라이선스와 직접 만든 것이 함께 사라집니다.** 그래서 ⑤-A 로 먼저 복사합니다.
> 앱을 지울 생각이 없다면 이 문서 대신 맨 위의 **완전 초기화 버튼**을 쓰세요 — 그쪽이 이 넷을
> 지켜 주고, 지운 것도 되돌릴 수 있습니다.

## 3단계 — `/usr/local/bin` 에 남은 것 정리 (0단계를 못 했을 때만)

0단계에서 **"셸 cys 해제"** 를 눌렀다면 이미 정리됐습니다. 4단계로 가세요.

앱을 먼저 지워 버렸다면 `/usr/local/bin` 에 우리 바로가기나 백업본이 남아 있을 수 있습니다.
먼저 **무엇이 남았는지만** 봅니다. 아래 줄은 목록을 보여 줄 뿐 **아무것도 지우지 않습니다.**

```bash
ls -l /usr/local/bin/cys /usr/local/bin/cysd /usr/local/bin/*.cys-backup-* 2>/dev/null
```

- 아무것도 안 나오면 정리할 것이 없습니다 → 4단계로.
- 뭔가 나왔다면 **여기서 지우는 명령을 직접 치지 마세요.**
  `/usr/local/bin/cys` 라는 **이름**은 그것이 우리 것이라는 보장이 되지 못합니다. 같은 자리에
  Homebrew로 설치했거나 직접 빌드한 **남의 진짜 `cys`** 가 있을 수 있고, 이름만 보고 지우는 명령은
  그 둘을 구분하지 못합니다(지우면 되돌릴 수 없습니다).

**지우는 절차의 정본은 [docs/INSTALL.md](INSTALL.md) §B 의 "수동 해제" 블록 하나입니다.**
그 블록은 ①그 자리가 바로가기(심볼릭 링크)인가 ②그 바로가기가 `cys.app` 안을 가리키는가 —
**둘 다 통과할 때만** 지우고, 아니면 이유를 적고 건너뜁니다. 통째로 복사해 붙여 넣으세요.

> 왜 그 블록을 이 문서에 베껴 두지 않았나: 같은 절차가 두 곳에 있으면 한쪽만 고쳐져 서로 다른 말을
> 하게 됩니다. 이 프로젝트가 실제로 그렇게 어긋난 적이 있어서, **정본은 §B 한 곳**으로 둡니다.

목록에 `cys.cys-backup-<숫자>` 같은 파일이 보였다면 그것은 **설치할 때 밀려난 남의 원본**입니다
(`<숫자>`는 백업한 시각의 epoch 초). 같은 §B 의 **"백업본을 손으로 되돌리기"** 절이 제자리에
되돌리는 절차를 알려 줍니다 — 되돌린 다음, 정말 필요 없을 때만 지우세요.

## 4단계 — 다 지워졌는지 확인

터미널에 아래 두 줄을 입력합니다:

```bash
launchctl list | grep -i cys
pgrep -fl cysd
```

**둘 다 아무것도 안 나오면 성공**입니다.

## 5단계 — 새로 설치해서 처음부터

홈페이지(www.cysinsight.com)에서 최신 DMG를 받아 설치하면 완전한 처음 상태로 시작합니다.

# (선택) 마지막 흔적까지: Claude Code 훅 정리

cys는 설치 중에 Claude Code(claude 명령)의 설정 파일에 자기 연결 고리(훅)를
등록합니다. 위에서 `.cys`를 지우면 이 고리는 **끊어진 채로만 남고 아무 동작도 하지
않지만**, Claude Code를 따로 쓰시는 분은 세션 시작 때 "hook 오류" 같은 메시지를
볼 수 있습니다. 신경 쓰이면 아래처럼 정리하세요.

- **윈도우**: 파일 탐색기 주소창에 `%USERPROFILE%\.claude` 입력 → `settings.json`
- **맥**: 터미널에 `open ~/.claude` 입력 → `settings.json`

이 파일을 메모장(맥은 텍스트 편집기)으로 열어 `"hooks"` 항목 안에서 `.cys` 라는
글자가 들어간 줄 묶음만 지우고 저장합니다. 잘 모르겠으면 `settings.json` 파일
이름을 `settings.json.bak`으로 바꿔두기만 해도 됩니다(Claude Code 설정이 기본값으로
돌아갈 뿐, **로그인은 풀리지 않습니다**).

# 자주 묻는 질문

**Q. 정말 PC 포맷은 안 해도 되나요?**
네. cys가 컴퓨터에 남기는 것은 ①앱 ②숨김 데이터 폴더(`.cys`) ③상태 폴더(맥은
`~/.local/state`의 `cys`·`cys-dept-…`·`cys-trash`, 윈도우는 `%LOCALAPPDATA%\cys` 와
`%USERPROFILE%\.local\state\cys-trash`) ④(맥) 자동 실행 등록 ⑤Claude Code 훅
⑥앱 화면 저장값(테마·배치 — 맥은 `~/Library`, 윈도우는 `%LOCALAPPDATA%\com.cysjavis.terminal`)
⑦(맥 · **"셸에 cys 설치"를 눌렀을 때만**) `/usr/local/bin` 의 바로가기 `cys`·`cysd` 와, 설치할 때
밀려난 남의 원본을 보관해 둔 `cys.cys-backup-<숫자>` 파일,
이 일곱이 전부입니다. 위 단계가 일곱을 모두 다룹니다 — 다만 ⑦은 **지우는 것이 아니라 되돌리는**
단계입니다(0단계 또는 3단계). 그 자리에는 우리 것이 아닌 파일이 있을 수 있기 때문입니다.

**Q. 앱 안의 "완전 초기화" 버튼과 이 문서는 뭐가 다른가요?**
지우는 **범위**가 다릅니다. 버튼(`cys factory-reset`)은 앱을 그대로 두고 데이터만 되돌리며,
**라이선스 파일 · 직접 만든 지침·스킬·훅(`local` 폴더) · 직접 넣어 둔 열쇠 파일(`*.env`)·인증서 ·
지금까지의 격리 보관본(`cys-trash`)** 을 **일부러 남깁니다**. 게다가 지운 것은 격리 보관되어
되돌릴 수 있습니다. 이 문서는 **앱까지 없애는** 절차라 그 넷도 함께 지웁니다 — 그래서 맥은
2단계 ⑤-A, 윈도우는 2단계 4번에서 **먼저 복사**하라고 안내합니다. 앱을 남길 생각이라면 이 문서
대신 버튼을 쓰세요.

**Q. 부서를 앱에서 지웠는데 왜 자꾸 돌아왔나요?**
부서 정보가 `.cys` 폴더에 남아 있으면 데몬이 되살릴 수 있습니다. 이 가이드는
데몬을 먼저 완전히 끄고 `.cys`를 지우기 때문에 되돌아오지 않습니다.

**Q. 지우다가 중간에 실패하면요?**
어느 단계든 처음부터 다시 순서대로 실행해도 안전합니다(이미 지워진 것은 건너뛰어집니다).
