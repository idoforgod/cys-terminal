# cys 터미널 v0.14.7

## 부트스트랩 품질 캠페인 — "너는 마스터다" 체인 전면 강화

핵심 체인(마스터 선언→각성→팀 기동) 전수 감사에서 확정된 결함 82건(P0 1·P1 23·P2 36·P3 22)을
웨이브 W0~W5(7단)로 전량 수리했다. 검증 계보: 감사 2방면 → 적대 재감사(28 에이전트 · 반박-우선 · 원 감사
전면 오류 0·부분 교정 5·신규 발견 34) → 외부 리뷰어 2기 5라운드(전 BLOCK 수용·양 ACCEPT) →
상시 건강성 게이트 신설(1커맨드 러너 · 결함 전량 회귀 검체 매핑).

### 사용자 체감 변화
- **각성 이원 경로 복원**: 탭에서 `claude`를 직접 타이핑해도 마스터 선언이 발화한다(개인 프로필에
  각성 훅 멱등 병합 — 사용자 항목 불가침·옵트아웃 `CYS_NO_PERSONAL_HOOK_MERGE=1`). cys 밖
  세션(VS Code 등)에서는 발화하지 않는다(오발화 게이트).
- **선언 감지 정밀화**: "너는 마스터다. 오늘 뭐부터 할까?" 같은 선언+질문 혼합 입력이 이제
  발화한다(절 경계 스코프 억제 — python 단일 감지기·실사용 corpus 회귀). "네가/니가/당신이" 표기 지원.
- **재선언 자가치유**: 에이전트만 죽고 좌석이 남은 상태에서 재선언이 무위로 돌던 영구 루프(P0) 소멸 —
  결손 판정·생존 술어가 check와 단일 소스로 통일되고, 죽은 좌석은 자동 회수 체인을 탄다.
- **wakeup 홍수 해소**: 생존점검 wakeup이 CEO/부서장 stdin을 잠식하던 부작용 제거 — idle은
  배지·원장 전용, 확증된 stall·노드 사망만 1줄 digest(CSO 1차 수신). 오발화(라벨 미조인 "생존미상")
  근절. 전자동 생존점검 목적은 유지된다.
- **알람 자동 소멸**: 모든 토스트가 종류 불문 유한 수명(일반 8s·경고 60s·진행형 180s) + 수동 닫기 +
  Control Center 알람 이력 탭. '팀 기동 경고' 영구 잔존 소멸.
- **기동 실패 자가 정리**: launch-agent 실패 시 고아 좌석(role 점유 잔존) 자동 롤백. 폴더신뢰
  자동확인 1회 전송·소멸 확인. 기동 중 사람 입력 시 지침 주입이 큐로 자동 전환(유실 0).
- **Windows 안전 일괄**: 훅 28종 크로스플랫폼 프리루드(경로·인터프리터·로케일), 부트 락
  Windows 실효화(스테일 회수·영구 Busy 불가능성), 허위 "발화됨" 보고 제거, Windows CI 실기
  검증 잡 신설.
- **GUI 부트 단일 계약**: ▶CEO/▶부서장 버튼이 CLI와 같은 부트 체인·같은 typed 진단을 쓴다.
  ★행동 변화: 부서장 버튼이 이제 CEO 티켓 게이트를 정상 경유한다(티켓 부재 시 안내 후 단독 각성 —
  종전의 GUI 단독 우회는 계약 분기라 제거).
